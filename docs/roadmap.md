# Utvecklingsplan

## 1. Stabil kartgrund

- Byt till geografiska koordinater och GeoJSON för punkter och polygoner.
- Gör det möjligt att flytta hörnpunkter och ändra befintliga områdens geometri.
- Beräkna areal och validera områden mot jaktmarkens gräns.
- Testa kartlager, ritning och GPS i Safari på iPhone och Chrome på Android.

## 2. Gemensamt jaktlag

- Inloggning och säker serverlagring.
- Inbjudningar och roller med serverkontrollerade behörigheter.
- Deltagande, tilldelade pass och uppdateringar för jakter.

## 3. Mobil och offline

- Bestäm PWA eller native mobilapp utifrån kraven på GPS i bakgrunden.
- Välj kartleverantör som tillåter offlinekartor.
- Nedladdning av kartområden med storleksvisning och radering.
- Lagra ändringar offline och synkronisera vid återanslutning.
- Synlig status för GPS-noggrannhet och kartornas aktualitet.

## 4. Inför verklig användning

- Testa på riktiga mobiler och i svag täckning.
- Inför backup, import/export, dataskydd och hantering av positionsdelning.
- Koppla verifierade jaktmarker och fastställ drift och kartlicenser.
